# DevTask AI - Product Requirement Document (PRD)

## Overview
A smart task management application for developers powered by Claude AI.

## Core Features
1. User Authentication (Login / Register)
2. Task Management (Create, Read, Update, Delete - CRUD)
3. AI Task Breakdown (Claude API integrated)
4. Dashboard & Progress Tracking

## Tech Stack
- Frontend: React + TypeScript
- Backend: Node.js + Express
- Database: PostgreSQL
- AI: Anthropic Claude API
